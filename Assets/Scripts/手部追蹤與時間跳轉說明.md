# 手部追蹤與播放時間跳轉

本文件記錄目前程式中已存在的手部輸入與 seeking 行為，不再保留早期尚未實作的範例程式碼。

## 手部追蹤

Meta Avatar 的手部動畫由 Avatar SDK 的 input provider 驅動，因此 Avatar hierarchy 不一定包含可直接指定的左右手 GameObject。`OrigamiStepGuideSimple` 支援兩種讀取方式：

1. 指定場景中的 `OVRHand` 元件。
2. 透過 `OVRPlugin.GetHandState()` 讀取手部與 pinch 狀態。

在 Quest 上測試前，請確認：

- Meta XR hand tracking 已啟用。
- 專案設定允許 Controllers and Hands 或 Hands Only。
- Trigger Distance 與 Pinch Threshold 適合場景比例。
- 左右手座標和提示物件使用一致的世界座標。

## 播放時間跳轉

目前 `AvatarRecordingManager` 與 `StudentPlaybackManager` 已包含 `JumpToTime()` 路徑。時間跳轉需要同步處理：

- Avatar recording frame
- Audio sample position
- Origami step event
- Alembic animation time
- 播放介面狀態

錄製資料包含帶時間戳的 Avatar frame、連續 audio samples，以及 origami step events。Seeking 時應使用同一個 target time 更新所有資料來源。

## 測試重點

- 跳到錄製開頭、步驟邊界與結尾。
- 在播放與暫停狀態分別進行 seeking。
- 確認聲音沒有落後或提前。
- 確認跳轉後第一個 Avatar frame 不會產生姿勢突變。
- 確認 Alembic 動畫與目前步驟一致。
